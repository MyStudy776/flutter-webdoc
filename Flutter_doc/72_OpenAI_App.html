6. understand speech_to_text package -

speech_to_text package in Flutter allows you to integrate speech recognition functionality into your applications.
 This package provides an easy-to-use API for listening to user speech, converting it to text, and handling the recognition results.
 
1st import the package :
 - import 'package:speech_to_text/speech_to_text.dart';
 - import 'package:speech_to_text/speech_recognition_result.dart';

2nd - Initialize an instance of SpeechToText class to access speech recognition functionalities.
    - final SpeechToText speech = SpeechToText();  [object creation]
	- call it on initState() 

3rd - Before starting to listen for speech input, it's important to check if speech recognition is available on the user's device. 
    - You can use the initialize() method provided by SpeechToText for this purpose:
	   void initializeSpeechToText() async {
          bool available = await speech.initialize();
          if (available) {
            // Speech recognition is available, you can proceed
          } else {
            // Speech recognition is not available on this device
          }
        }


4th - Once you've initialized the SpeechToText instance and verified availability, you can start listening for speech input. 
    - void startListening() async {
       await speech.listen(
         onResult: (SpeechRecognitionResult result) {
           if (result.finalResult) {
             // Speech recognition is finalized, handle the recognized text
             String recognizedText = result.recognizedWords;
             print('Recognized Text: $recognizedText');
           }
         },
       );
     }

- onResult - callback function  that gets called whenever there is a speech recognition result.
  result   -  parameter contains information about the recognized words.

5th - You can stop listening for speech input using the stop() method. 
    - For example, you might stop listening when a certain condition is met in your app:
	
	void stopListening() {
      speech.stop();
      }



6th.  override the dispose() method in your widget to release the SpeechToText instance:

       @override
        void dispose() {
          super.dispose();
          speech.stop();
          speech.cancel();
        }
