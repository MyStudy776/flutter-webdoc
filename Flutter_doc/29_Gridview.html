1. Use GridView.count -

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    var aryColors = [
      Colors.orange,
      Colors.green,
      Colors.yellow,
      Colors.blue,
      Colors.deepPurpleAccent,
      Colors.cyanAccent,
      Colors.teal
    ];
    return MaterialApp(
      title: 'Flutter Demo',


      home: Scaffold(
        appBar: AppBar(
          backgroundColor: Colors.purple,
          title: Text('Hello'),
        ),
    body: GridView.count(crossAxisCount: 2,
    children: [
      Container(color: aryColors[0],),
      Container(color: aryColors[1],),
      Container(color: aryColors[2],),
      Container(color: aryColors[3],),
      Container(color: aryColors[4],),
      Container(color: aryColors[5],),
      Container(color: aryColors[6],),
    ],),



      )
    );

  }
}






===


mainAxis -->means row
crossAxis ---> means column
GridView.count(crossAxisCount: 2 ---> the total width will be divided 2 column.
children ---> it is an attribute of gridview. So no need to use row/column widget.
In gridview, the items are scrollable.

6. Use GridView.extent

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    var aryColors = [
      Colors.orange,
      Colors.green,
      Colors.yellow,
      Colors.blue,
      Colors.deepPurpleAccent,
      Colors.cyanAccent,
      Colors.teal
    ];
    return MaterialApp(
        title: 'Flutter Demo',


        home: Scaffold(
          appBar: AppBar(
            backgroundColor: Colors.purple,
            title: Text('Hello'),
          ),
          body: GridView.extent(
            maxCrossAxisExtent: 100,
            crossAxisSpacing: 11,
            mainAxisSpacing: 11,
            children: [
              Container(color: aryColors[0],),
              Container(color: aryColors[1],),
              Container(color: aryColors[2],),
              Container(color: aryColors[3],),
              Container(color: aryColors[4],),
              Container(color: aryColors[5],),
              Container(color: aryColors[6],),
            ],),



        )
    );

  }
}


GridView.extent - 
Here we have given a particular width to the box - 100 size(maxCrossAxisExtent: 100). It will create as much box as per the width.
If you move the phone in landscape mode or web screen size big or small, according to the width the boxes will be created. 


But in GridView.count(crossAxisCount: 5 --> only 5 boxes will be created and the box width will be increase or decrease  as per the screen width.

7. Use GridView Builder - SliverGridDelegateWithFixedCrossAxisCount, similar function as gridview.count

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    var aryColors = [
      Colors.orange,
      Colors.green,
      Colors.yellow,
      Colors.blue,
      Colors.deepPurpleAccent,
      Colors.cyanAccent,
      Colors.teal
    ];
    return MaterialApp(
        title: 'Flutter Demo',
        home: Scaffold(
          appBar: AppBar(
            backgroundColor: Colors.purple,
            title: Text('Hello'),
          ),
          body: GridView.builder(
              itemBuilder: (context, index) {
                return Container(
                  color: aryColors[index],
                );
              },
              itemCount: aryColors.length,
              gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
                  crossAxisCount: 3,
                  crossAxisSpacing: 11,
                  mainAxisSpacing: 11),

          ),
        ));
  }
}



It will use howmany colors are used in array as per array length.
It is scrollable.
crossAxisCount: 3 --> only 3 column will be created and it will resize as per the screensize.
no need to put manually the array item. Automatically it will build as per the list.
