Row and Column widget

1. column widget -

return Scaffold(
      appBar: AppBar(

        backgroundColor: Theme.of(context).colorScheme.inversePrimary,

        title: Text('Flutter Container'),
      ),
      body: Column(
        children: [
          Text('A', style: TextStyle(fontSize: 25),),
          Text('B', style: TextStyle(fontSize: 25),),
          Text('C', style: TextStyle(fontSize: 25),),
          Text('D', style: TextStyle(fontSize: 25),),
          Text('E', style: TextStyle(fontSize: 25),),
        ],
      )
    );
  }
}


children: [] --> It will accept all type .
children <Text>: [] -->It will accept only Text widget.
children <Widget>: []-->It will accept all type of widget.


Row ---> horizontal - MainAxisAlignment, vertical - CrossAxisAlignment
Column ---> Vertical - MainAxisAlignment, horizontal - CrossAxisAlignment

Note -
mainAxisAlignment: MainAxisAlignment.spaceEvenly ---> It will distribute space equally among all the rows or columns, including the space before start and after end row/column.
                                                 
or
mainAxisAlignment: MainAxisAlignment.spaceAround ---> It will distribute space equally among all the rows or columns.
                                                      But It will give half space to the start and half space to the end of the row/column.
or
mainAxisAlignment: MainAxisAlignment.spaceBetween---> There is no space at before start and after end row/column.
or
mainAxisAlignment: MainAxisAlignment.center----> All the rows/columns will be centered and no space in between.
or
mainAxisAlignment: MainAxisAlignment.start
or
mainAxisAlignment: MainAxisAlignment.end
or
mainAxisAlignment: MainAxisAlignment.stretch  --->The whole widget will be stretched as per the width of the container.

}

            color: Colors.red,
            width: 300,
            height: 300,
            child: Column(
              mainAxisAlignment: MainAxisAlignment.start,
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Row(
                  mainAxisAlignment: MainAxisAlignment.spaceEvenly,

                      mainAxisAlignment: MainAxisAlignment.start,
