34. Navigator.of(context).pushReplacementNamed -

In HomePage , we can see one back button in AppBar to go to Login Page. 
But in real life once we entered the login page, We no need to go back to login page again. So for that reason we do not need any back button in HomePage. 
So to make this changes we will use - pushReplacementNamed  instead of - pushNamed  in navigator of Login page.

It means push to /home and replaced with Login page.

                           Navigator.of(context).pushReplacementNamed('/home');

==========

The error you're encountering indicates that the Toolbar widget is not being recognized as a valid value for the appBar parameter of the Scaffold widget. This is because the AppBar expects a widget of type PreferredSizeWidget for its appBar parameter, and Toolbar is not a subclass of PreferredSizeWidget.

To fix this issue, you need to ensure that your Toolbar widget conforms to the PreferredSizeWidget interface. This interface requires implementing the preferredSize property, which specifies the preferred size of the widget.
