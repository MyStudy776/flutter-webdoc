4. ConstrainedBox

Here we given min width and height to SizedBox.shrink by using constrained box, but still output does not show,
because, the sizedbox is under center widget and center widget does not have any height and width.
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: Text('Hello'),
        ),
        body: ConstrainedBox(
          constraints: BoxConstraints(
            minWidth: 200,
            minHeight: 40,
            maxHeight: 80,
            maxWidth: 400,
          ),
          child: Center(
            child: SizedBox.shrink(
              child: ElevatedButton(
                onPressed: () {},
                child: Text('Hello World'),
              ),
            ),
          ),
        ),
      ),
    );
  }
}

10. ConstrainedBox Widget -

A box having limit --> maxwidth, maxheight, minwidth, minheight.
By default constraint box having one child.

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {

  @override
  Widget build(BuildContext context) {

    return MaterialApp(
      home: Scaffold(
          appBar: AppBar(title: Text('My home page')),
          body:ConstrainedBox(
            constraints: BoxConstraints(
              maxWidth: 200,
              maxHeight: 100,
            ),
            child: Text('Hello World Hello World Hello World Hello World Hello World 
			Hello World Hello World Hello World Hello World Hello World Hello World Hello World Hello World Hello World', 
			style: TextStyle(
              fontSize: 21,
              overflow: TextOverflow.fade  ----------->if text will come out of the box, then it will show like this ......

          )
      ),
    );
  }
}
