18. Passing Function -

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  void fun1() {
    print("Answer1");
  }

  @override
  Widget build(BuildContext context) {


    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: Text('Hello'),
        ),
        body: Column(
          children: [
             ElevatedButton(onPressed: fun1(), child: Text("belo Q"))
          ],
        )
      ),
    );
  }
}


ElevatedButton(onPressed: fun1()--->error, This expression has type void so its value can not be used.

Here as the code read by compiler , it will execute the function fun1().It does not wait for the button to be pressed.
Here the return value of fun1() is passe to onpressed.



So to correct this use like this -

ElevatedButton(onPressed: fun1, child: Text("bolo Q"))--->pass the function name, not to call the function.
