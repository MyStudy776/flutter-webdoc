Step 4: Connect the Repository to Vercel
Go to Vercel's dashboard.

Click "New Project".

Select "Import Git Repository".

Log in to GitHub (if prompted) and authorize Vercel.

Find your repository (e.g., my-website) and click "Import".

Configure the settings:

For static sites, leave the build command empty (Vercel will assume it's a static site).
Set the output directory to / (the default).
Click "Deploy".
