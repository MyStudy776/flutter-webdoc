Use of Provider-

1. What is provider ? -

- Instead of set state(), we can use provider.
- In ste state , It will rebuild the whole App, but using provider it will rebuild only the portion where it is used.
- provider is like a data box, the data present in the provider can be accessed any pages.
- Let say page A, changes the value of x=0 variable present in the provider class , to x=1, then other pages can access the x=1.
-Provider is helpful to share the data between pages.
- Data is outside UI, same data can be accesss in many screen.

2. what are the part of provider

Provider has 4 main parts

- Model (Data + Logic)
- Provider (Giver of data)
- Consumer / watch (Listener)
- read (Action caller)

3. Types of Provider 

1. Provider – simple data
2. ChangeNotifierProvider – data + notify UI 
3. FutureProvider – API call
4. StreamProvider – live data
5. MultiProvider – many providers

4. How to use ?-

1. create a provider file/class ---> put the data and logic , which need to be changed.
                     E.g:  class Counterprovider extends ChangeNotifier
					        notifyListeners(); //rebuild the data

2. main.dart file ---->Link the provider file to your App
                        ChangeNotifierProvider(
						  create: (_)=>Counterprovider(),//provider file
                          child:  MyApp(),//Your App


3. Your App ----> To show the data (text):
                      Consumer<Counterprovider> //calls the provider file
					  counter1.count.toString(), // use the provider data


            ----->On pressing the button , Logic will be applied
			        onPressed: context.read<Counterprovider>().add //calling the method of provider file

counter_provider.dart
------------------
import 'package:flutter/material.dart';

class Counterprovider extends ChangeNotifier {

int count = 0;

void add() {
  count++; //Logic
  notifyListeners(); //rebuild the count variable
}

void remove() {
  if (count > 0) {
      count--;
      notifyListeners();//rebuild the count variable
    } 
}

}

import 'package:flutter/material.dart';

class ToggleProvider extends ChangeNotifier {
  bool isVisible = true;

  void toggle() {
    isVisible = !isVisible;
    notifyListeners();
  }
}
