ListView widget -

1. What is List View 

- ListView is a widget that shows items in a vertical scrollable list
- It will automaticall scroll horizontally and vertically when content is beyond the screen.

2. example 1 : Listview

Simple Listview
-----------------
ListView(
  children: [
    ListTile(title: Text("Apple")),
    ListTile(title: Text("Banana")),
    ListTile(title: Text("Orange")),
  ],
)


- Here You already know There are 3 items in advance.
- All items are created at once
- Easy to write
- Good for small lists
- but If list is very big → memory waste

3. example 2 : Listview with Listview builder

 Listview
-----------------
ListView.builder(
  itemCount: 5,
  itemBuilder: (context, index) {
    return ListTile(
      title: Text("Item $index"),
    );
  },
)

- You don’t know how many items, or list is big, in this case builder will be used.
- Items are created only when needed
- Better performance
- Best for dynamic data

4. Difference betwen List view and SingleChildScrollView -


SingleChildScrollView
------------------------
SingleChildScrollView(
  child: Column(
    children: [
      Text("Item 1"),
      Text("Item 2"),
      Text("Item 3"),
      Text("Item 4"),
      Text("Item 5"),
    ],
  ),
)


- It makes ONE child scrollable.That child can be: Column,Row or Container .
- It expects a single child, which is typically a column, row, or another widget
- All widgets are built at once
- Good for forms or static UI
- If items are many: High memory usage, slow down the app.
- It uses when you have a single child that needs to be scrollable (e.g., a form with various input fields).
- Use SingleChildScrollView when:

✔ Login / Register page
✔ Form page
✔ Profile page
✔ Static content



ListView
-----------
- It is a scrollable list made for many items.
- It can have multiple children, and it's designed to handle long lists efficiently.
- It only renders/loads the items that are currently visible on the screen, making it much more efficient for long lists.
- Use it when you have a list of items (e.g., messages in a chat app, articles in a news app) and you want to efficiently scroll through them.

7. Listview Builder -

- It will manage when large amount of data will be inserted.
- It will build the list view.
Here we will define how one item how it looks like. According to that all the items in array will be changed.
we will get an index in ItemBuilder.- ListView.builder(itemBuilder: itemBuilder)
or we can use context - ListView.builder(itemBuilder: (context, index)
itemcount---> Specifies howmany item need to build.

8. Listview Builder Example 1 -

import 'package:flutter/material.dart';

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
          appBar: AppBar(
            title: Text('Hello'),
            backgroundColor: Colors.orange,
          ),
          body: ListView.builder(itemBuilder: (context, index){
            return Text('one', style: TextStyle(fontSize: 21, fontWeight: FontWeight.w500),);
           },
          itemCount: 5, //It will create 5 items in the list
      ),
    ),
    );
  }
}

  @override
  Widget build(BuildContext context) {
    var arrNames = ['Rajesh','Monika', 'Raman','Kohli', 'Birat', 'Ranveer'];
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: Text('Hello'),

          return Text(arrNames[index], style: TextStyle(fontSize: 21, fontWeight: FontWeight.w500),);

          itemCount: arrNames.length,
          itemExtent: 100, ----->it will give space between items
        ),
      ),
    );
  }
}



itemExtent: 100, --->After this space came between items. when items are out of screen, then these will be scrollable.
scrollDirection: Axis.horizontal, --->items are in horizontal direction

Advantage -

when scrolling the listview builder item, it will destroy the the item from memory, which are not visible on the screen. So always the memory is recycled.

          },
        ),
      ),
    );
  }
}





return Divider(height: 100, thickness: 2,); --->The items are separated by a divider. 
                                            Here divider is the separataor.
                                            We can put any widget as a separator.

  }
}

class MyHomePage extends StatefulWidget {

  @override
  State<MyHomePage> createState() => _MyHomePageState();
}

class _MyHomePageState extends State<MyHomePage> {
  List<String> fruits = ['Orange', 'Apple', 'Mango', 'Banana','Orange', 'Apple', 'Mango', 'Banana'];
  Map fruits_person = {
    'fruits': ['Orange', 'Apple', 'Mango', 'Banana','Orange', 'Apple', 'Mango', 'Banana'],

      appBar: AppBar(
        title: Text('List view'),
        backgroundColor: Colors.cyan,
        elevation: 0,
      ),
      body: Container(
        child: ListView.builder(
          itemCount: fruits.length,
             itemBuilder: (context, index) {
               return Card(
                 child: ListTile(
                   onTap: () {

                   title: Text(fruits_person['fruits'][index]),
                   subtitle: Text(fruits_person['names'][index]),
                 ),
               );
             },
           ),


      )
    );
  }
}

  State<Listview1> createState() => _Listview1State();

    return Scaffold(

        padding: EdgeInsets.all(10),
       children: [

             color: Colors.blue,
             height: 100,
             margin: EdgeInsets.symmetric(vertical: 10),
             alignment: Alignment.center,
             //child: Text('number is $i'),
             child: Text(i.toString(),style: TextStyle(color: Colors.amber),),
          )
       ],
      ),
      );
  }
}

17. Listview example 3rd Example using Map

import 'package:flutter/material.dart';

class Listview1 extends StatefulWidget {
  const Listview1({super.key});

  @override
  State<Listview1> createState() => _Listview1State();
}

class _Listview1State extends State<Listview1> {
  List<int> numbers = [45, 67, 39, 17];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        backgroundColor: Colors.yellow,
      ),
      body: ListView(
        padding: const EdgeInsets.all(20),
        children: numbers.map((item) {
          return Container(
            color: Colors.blue,
            height: 100,
            margin: const EdgeInsets.symmetric(vertical: 10),
            alignment: Alignment.center,

            
            child: Text(
              item.toString(),
              style: const TextStyle(color: Colors.white, fontSize: 20),
            ),
          );
        }).toList(), 
      ),
    );
  }
}
