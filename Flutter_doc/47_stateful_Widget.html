8.Asynchronous Function -

- It is used to perform heavy operations such as downloading images, getting data from the API or database etc.

- An asynchronous function will await the execution of a promise, and an asynchronous function will always return a promise.

- The promise returned by an asynchronous function will resolve with whatever value is returned by the function.

Benefit -
- we can perform heavy operations .
- UI experience become smoother.
- App will not crash or freeze during the execution of heavy operations.
- Make code more usable and understandable.

Once you clicked the go home button, init function will execute, The initstate(), will try to execute first the getData(), but getData()
uses future.delayed, so it will skip it for 7 second, and mean while it will go for the next execution - showData().
In showData(), username value is not assigned yet because, it depends on showData(), so it will display null. - my user is: null.
After that next execution will be run - print("This is a init state");. After  7 second passed, getData() will execute - assign value to 
username variable and print - "7 seconds have passed".

  Note    
what happens -
In Async - Functions start but return the value some delayed.
In Future.delayed - Function execution start after some delayed.
