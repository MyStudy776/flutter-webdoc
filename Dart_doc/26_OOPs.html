2. Polymorphism -

Poly = many
Morph = forms
So it means “many forms.”

Polymorphism allows one method or object to behave differently based on which class is using it.
You can call the same method name on different objects,and each one can do something different!


Polymorphism - It is the ability of object to take many form.
             - This thing achieved using inheritance and method overriding.
			 - I allows object of different class will be treated as object of common superclass.


			 
class Animal{
  void sound(){
    print("Animal making sound");
  } 
}
  
  
class Cat extends Animal{
  @override
    void sound(){
    print("Cat making sound");
  }
}

class Dog extends Animal{
  @override
    void sound(){
    print("Dog making sound");
  }
}

void main() {
  Animal obj1 = Cat();
  obj1.sound();
  
  obj1 = Dog();
  obj1.sound();
  
  Cat obj2 = Cat();
  obj2.sound();
  
  Animal obj3 = Animal();
  obj3.sound();
  
}

o/p
====
Cat making sound
Dog making sound
Cat making sound
Animal making sound

Another example of polymorphism -

class Shape {
  void draw() {
    print('🟦 Drawing a shape...');
  }
}

class Circle extends Shape {
  @override
  void draw() {
    print('⚪ Drawing a Circle');
  }
}

class Square extends Shape {
  @override
  void draw() {
    print('⬛ Drawing a Square');
  }
}

void main() {
  List shapes = [Circle(), Square(), Circle()];

  for (var shape in shapes) {
    shape.draw(); // same method name → different behavior
  }
}



o/p
-----
⚪ Drawing a Circle
⬛ Drawing a Square
⚪ Drawing a Circle


Imagine a drawing app like MS Paint 🎨
You click "Draw", and it can draw:

Circle

Square

Rectangle
without writing different code for each one!

That’s the power of polymorphism — same code, different behavior.

Abstract class

3. Abstract class -

Abstraction - It is hiding of internal details and complexity of object and only exposing the essential features and functionalities.

abstract class Animal{
  void sound();  ---------------------->Hiding internal details
}
  
  
class Cat extends Animal{
  
  @override
    void sound(){
    print("Cat making sound");
  }
}

class Dog extends Animal{
  
  @override
    void sound(){
    print("Dog making sound");
  }
}

void main() {
  Animal obj1 = Cat();
  obj1.sound();
  
  obj1 = Dog();
  obj1.sound();
  
  Cat obj2 = Cat();
  obj2.sound();
  
  Animal obj3 = Animal(); ----------->error . Abstract class can not be instantiated.
  obj3.sound();
  
}

class Student <T>{

  Student(this.name, this.grade); //constructor
}

void main() {

 
  final obj2 = Student('ram', 10);
  print(obj2.name);
  print(obj2.grade);

<T> ---> generic --> if we give any name it will consider the type as per the value inserted.
