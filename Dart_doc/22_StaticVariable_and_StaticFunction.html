Static variable and Static function

1. Static variable and Static function -

Creating object is an memory consumption.
If we do not want to create any object so we can use static variable and static function.

void main() {
    
//create instance
   final con = Constantt(); 
   
   print(con.greet); //object creation , consuming memory
   print(con.bye);

 }


class Constantt {
  
String greet = 'Hello, How are u?';
String bye = 'Bye forever';
  
 }
 
o/p
===
Hello, How are u?
Bye forever

2. By using Static - -

But using Static -

void main() {
 
   print(Constantt.greet); 
   print(Constantt.bye); 
   print(Constantt.fun1()); 
 }


class Constantt {
static String greet = 'Hello, How are u?'; //static variable
static String bye = 'Bye forever'; //static variable
static int fun1() {   //static function
   return 10;   
 }
 
  }
 
 o/p
 ====
Hello, How are u?
Bye forever
10
