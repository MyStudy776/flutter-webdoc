46. difference between extend and implement in dart class -

1. What is extends?
👉 Think of it like:

A child copying everything from the parent.

If Class B extends Class A:

B gets all the properties of A

B gets all the methods of A

B can use them directly

B can also change them (override)

✔ Example:
class Animal {
  void eat() {
    print("Animal eating");
  }
}

class Dog extends Animal {
  void bark() {
    print("Dog barking");
  }
}

void main() {
  Dog d = Dog();
  d.eat();  // from Animal
  d.bark(); // from Dog
}

💡 Meaning:

Dog extends Animal → Dog is an Animal.

🎭 2. What is implements?
👉 Think of it like:

A class promises to follow a rule/contract.
But it must write all the methods by itself.

If Class B implements Class A:

B does NOT get code from A

B must re-write all methods of A

B only gets method names, not the logic

✔ Example:
class Animal {
  void eat() {}
}

class RobotDog implements Animal {
  @override
  void eat() {
    print("RobotDog charging instead of eating");
  }
}


Here RobotDog must rewrite eat() because implements means:

“I promise to create these methods myself.”
