Lexical Scope

1. Lexical scope -

void main() {
  int x = 10;

  void showX() {
    print(x); // can see x because it’s inside main
  }

  showX();
  // print(y); // ❌ can’t see y (defined inside showY)
}

void showY() {
  int y = 5;
  print(y);
}


Inner functions can see outer variables.
But outer functions cannot see inside variables.
