1. await async in Dart-

In Dart, async and await are keywords used in asynchronous programming to work with Futures.

Async :
==========
- When an async function is called, a Future is immediately returned.and the body of the function is executed later.
- - Asynchronous programming is crucial for handling operations that may take some time to complete, 
   .such as network requests or file I/O, without blocking the execution of the program
- The async keyword is used to mark a function as asynchronous. This means that the function can perform asynchronous operations, and it may return a Future.
  The presence of async in a function's signature allows the use of the await keyword inside that function.



e.g:
void hello() async { 
  print('something exciting is going to happen here...'); 
}

e.g:
Future<void> fetchData() async {
  // Asynchronous operations can be performed here
}


Await
=======
- Await expressions makes you write the asynchronous code almost as if it were synchronous.
- Typically, it is an asynchronous computation and is expected to evaluate to a Future.
- The await expressions evaluate the main function, and then 
  suspends the currently running function until the result is ready–that is, until the Future has completed. 
- The result of the await expression is the completion of the Future.
- Here we use the async modifier on the main method because we are going to run the hello() function asynchronously.
- Secondly, we place the await modifier directly in front of our asynchronous function. Hence, 
  this is frequently referred to as the async/await pattern.
- Just remember, if you are going to use await, make sure that both the caller function 
  and any functions you call within that function all use the async modifier.
  
- The await keyword is used to pause the execution of a function until the awaited operation completes. It can only be used inside a function marked as async.
- When you await a Future, the surrounding function is paused until the Future completes, and the result is then used.
e.g:
void main() async { 
  await hello(); 
  print('all done'); 
}

e.g:
Future<void> fetchData() async {
  // Asynchronous operation that returns a Future
  var result = await someAsyncFunction();

  // Code here will only execute after someAsyncFunction completes
}

2. A simple future example-

void main() {
  print('I order a pizza!');
  
  Future.delayed(Duration(seconds: 3), () {
    print('Pizza is ready!');
  });
  
  print('I play on my phone while waiting...');
}



output
========
I order a pizza!
I play on my phone while waiting...
Pizza is ready!



You go to a restaurant 🍽️ and order a pizza 🍕.
The waiter says: “Okay! It will take 5 minutes.”

Now, do you just stand there waiting? ❌
No — you play on your phone or talk to your friend while the pizza is being made.

When the pizza is ready, the waiter brings it to you. ✅

That’s what Future means in Dart!
It means:

“This thing will finish later, not now.”

See? The program didn’t wait 3 seconds — it kept doing other things.
That’s called asynchronous programming



When you use await, you can pause the program until the Future is done.

void main() async{
  print('I order a pizza!');
  
  await Future.delayed(Duration(seconds: 3), () {
    print('Pizza is ready!');
  });
  
  print('I play on my phone while waiting...');
}


o/p
====
I order a pizza!
Pizza is ready!    ---------- after 3 sec output will come.
I play on my phone while waiting...


Now the program waited until the pizza was ready before printing the next lines.


Future<String> makePizza() async {
  await Future.delayed(Duration(seconds: 2));
  return 'Your Pizza 🍕';
}

void main() async {
  print('Ordering...');
  String pizza = await makePizza(); // waits for the pizza
  print(pizza);
}
🧠 Explanation:

Future<String> → means this function will later give a String.

await makePizza() → waits until the function finishes.

After 2 seconds, we get 'Your Pizza 🍕'.

2. Example await and async -

Future<void> fetchData() async {
  print("Start fetching data...");

  // Simulating an asynchronous operation that takes 2 seconds
  await Future.delayed(Duration(seconds: 2));

  print("Data fetched!");
}

void main() {
  print("Before fetchData()");

  fetchData();

  print("After fetchData()");
}



o/p
======
Before fetchData()
Start fetching data...
After fetchData()
Data fetched! --------------->The output will come after 2sec



- In this example, fetchData() is an asynchronous function.that simulates a delay of 2 seconds using Future.delayed.
- The await keyword is used to wait for this delay.
- The output will demonstrate that the program doesn't block at the await statement, 
  allowing other operations to proceed while waiting for the asynchronous operation to complete.

sync* → means “I will generate values step by step.”

yield → gives a single value each time.

Stream countUp(int n) async* {
  for (int i = 1; i <= n; i++) {
    await Future.delayed(Duration(seconds: 1)); // wait 1 second
    yield i; // give next number
  }
}

void main() async {
  await for (var number in countUp(3)) {
    print(number);
  }
}

====

2
3

🧠 What happens:
Function countUp says: “I’ll send numbers one by one.”

It waits 1 second between each number using await Future.delayed(...).

In main, we say await for — it waits for each number to come before printing

Future

1. -

- Future represents a value, or error, that will be available at some time in the future.
- Dart uses futures to represent the result of an asynchronous operation.
- It's a fundamental concept in asynchronous programming, allowing you to work with computations that may not complete immediately.
- An asynchronous operation is one that doesn't block the execution of the program while waiting for the result. Instead, it allows the program to continue executing other tasks until the result is ready.
