46. Enum-

Imagine you have a box of fixed options.
You cannot add new things inside it.
You can only choose one from the list.

That box is called enum.

Why do we use enum?
=====================
- To store fixed, limited choices.

Example:
Days of the week
Colors
Order status
User roles
These things never change.

Enum is a list of constant values (options) that you can choose from.


void main() {

print(Gender.Male);
print(Gender.Male.index);
print(Gender.Male.index);

Gender x= Gender.Female;
print(x);

}


enum Gender {Male,Female,Others}
