47. mixin -

What is a mixin?

A mixin is like copy-paste power for a class.

You can take methods from another class and add them into your class without inheritance.

👉 A mixin is used to share reusable methods with many classes.

🎯 Why do we use mixins?

Because sometimes:

You don’t want to extend a class

You don’t want to implement a class

You only want to reuse some methods

Mixins solve this.

🍕 Simple Example

Imagine you have special abilities:

mixin Runner {
  void run() {
    print("Running fast!");
  }
}

mixin Swimmer {
  void swim() {
    print("Swimming in water!");
  }
}


Now any class can use these abilities:

class Human with Runner, Swimmer {}

void main() {
  Human h = Human();
  h.run();
  h.swim();
}

👉 Meaning:

Human is NOT a Runner
Human is NOT a Swimmer
But Human can run and can swim because we mixed-in those abilities.

💡 Mixins look like this:
mixin MixinName {
  // methods here
}


And used like this:
