2. Variable name rule-

Variable name or identifiers can’t be the keyword.
Variable name or identifiers can contain alphabets and numbers.
Variable name or identifiers can’t contain spaces and special characters, except the underscore(_) and the dollar($) sign.
Variable name or identifiers can’t begin with number.

4. Static variable -

void main()
{
int x = 10;
  print(x); --------> 10
  x = 20;
  print(x); --------> 20
  x = "aa";
  print(x); --------> error,A value of type 'String' can't be assigned to a variable of type 'int'.
}

5. dynamic variable -

void main()
{
dynamic x = 10;
  print(x); ----------> 10
  x = "aa";
  print(x); --------> aa
}

6. var keyword with initialization during declaration-

void main()
{
var x = 10;
  print(x); --------> 10
  x = 20;
  print(x); --------> 20
  x = "aa";
  print(x); --------> error,A value of type 'String' can't be assigned to a variable of type 'int'.
}

7. var keyword without initialization during declaration-

void main()

8. final -

void main()
{
  final x ; 
  x = 30;
  print(x); ----------> 30
  x = 20;
  print(x); ----------> error, Final variable 'x' might already be assigned at this point.
}

9. const -

void main()
{
  const x ; 
  x = 30;
  print(x); ----------> error, The const variable 'x' must be initialized.
}

10. final or const-

final : - once value is assigned, then it can not be changed. We can add or overwrite values.
const : - we must assign value to const variable during declaration.it will accept only if it has a value at compile  time.
        - It prevents if any value of the variable change accidentally.


variable initialization -

final string name1 = "aaa";
or
final  name1 = "aaa";
or
const name1 = "aaa";



final String pet = 'cat';   // set once when the program runs
const int daysInWeek = 7;   // fixed forever (compile-time constant)

12. static vs dynamic vs var -

var a = 10;--> The moment you assign the data to variable with var keyword it is replaced with the appropriate data type.
           ---> It is static variable
		   
var a;     --->Dynamic variable, any data type it will accept.

dynamic c; --->dynamic variable. any data type it will accept.

int a; --> static variable. It will accept only integer
int a = 10; --> static variable. It will accept only integer

final x; ---> must not initalize. Its value won't change
final int x;

const x = 30; --->must initalize. Its value won't change
const int x = 30;
