Inheritance

1. Inheritance -

Someclass ---> Vehicle --> Car

Vehicle --> car

Vehicle --> Truck

Inherits the property .
- In dart multiple inheritance not possible . That is: Vehicle1 --> car, Vehicle2 --> car . It is not possible.


Type of Inheritance
========
1. Single level inheritance
2. Multilevel Inheritance
3. Heridetary Inheritance

2. Single level Inheritance

class A{
  a(){
    print("A is called");
  }
}


class B extends A{
  b(){
    print("B is called");
  }
}


void main() {
  
  B obj1 = B();
  obj1.a();
  obj1.b();
}



output
=========
A is called
B is called

3. multi level Inheritance

class A{
  a(){
    print("A is called");
  }
}


class B extends A{
  b(){
    print("B is called");
  }
}


class C extends B{
  c(){
    print("C is called");
  }
}



void main() {
  
  C obj1 = C();
  obj1.a();
  obj1.b();
  obj1.c();
}



output
=======
A is called
B is called
C is called

4. Super constructor

Super Keyword - it is used to insert parent class property into child class.


class A{
  A(){
    print("A constructor is called");
  }
}

class B extends A{
  B(){
    print("B constructor is called");
  }
}

void main() {
  print("Calling all the constructors");
  B obj1 = B();
}



output
=========
Calling all the constructors
A constructor is called
B constructor is called

5. override in inheritance-

- override keyword is used to explicitly indicate that a method in a subclass is intended to override a method with the same signature in its superclass. 
- This helps in preventing accidental method name conflicts and ensures that you are intentionally overriding a method from the superclass.



void main() {
   
//Inheritance
   Car obj1 = Car();
   print(obj1.greet); //Car inherited the value from Someclass
   print(obj1.speed);
   obj1.accelerate();
   print(obj1.speed);
    }



class Someclass { 
  int speed = 15;
  String greet = 'Hello Dear';
  void accelerate() {
      speed = 40;
    }
  } 

class Vehicle extends Someclass {
  int speed = 10;
    
  @override  //It is optional. As the name for method "accelerate" is same in Someclass and Vehicle class . The Vehicle method overrides the Someclass
    void accelerate() {
      speed = 20;
    }
}


class Car extends Vehicle {
  int noofwheels = 4;
  void fun2() {
    print("There is something");
  }
}
