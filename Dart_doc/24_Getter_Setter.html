Getter and Setter

1. Getters and Setters -

-  A default getter/setter is associated with every class.
-  A getter has no parameters and returns a value.
-  setter has one parameter and does not return a value.
-  Getter and Setter are basically used to return a value.


Getter : - Are special functions that provides read write access to the object proeprties.


get - mean get the value
set - means set the value

class A {
  int? x; 
}

void main() {
  A obj1 = A();
  obj1.x = 40; // setter
  print(obj1.x); // getter.
}
