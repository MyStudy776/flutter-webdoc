Abstract Class

1. Concept of abstract class

First, imagine this story

You have a remote control design, Every TV remote must have:
- Power button
- Volume up
- Volume down

But how these buttons work can be different for:
- Sony TV
- Samsung TV
- LG TV

So the design is common, but implementation is different.
This design is called an abstract class.

2. What is an abstract class? (Simple definition)

- An abstract class is a class that cannot be used directly.
- It is only a blueprint for other classes.
- You cannot create object of an abstract class.
- abstract method with (no body).
- we can extend abstract class.

❌ What you CANNOT do
----------------------
abstract class Animal {

}

void main() {
  Animal a = Animal(); // ❌ ERROR,You cannot create object of an abstract class.
}

3. example of abstract class


abstract class Animal {
  void sound(); // abstract method (no body) //This says:👉 “Every animal must make a sound”
}

//Now create a real class
class Dog extends Animal {
  @override
  void sound() {
    print("Bark");
  }
}

class Cat extends Animal {
  @override
  void sound() {
    print("Meow");
  }
}

void main() {
  Animal dog = Dog();
  dog.sound(); // Bark

  Animal cat = Cat();
  cat.sound(); // Meow
}


Important rules (remember these)
==============================
✅ Abstract class can have:
-------------
✔ Abstract methods (without body)
✔ Normal methods (with body)
✔ Variables


❌ Abstract class:
--------------
❌ Cannot create object
❌ Must be extended

4. Why do we use abstract class?

Force rules
👉 Every child class must implement methods.

Code consistency
👉 Same method names everywhere.

Used in Flutter a LOT
Example:
State
StatelessWidget
StatefulWidget
