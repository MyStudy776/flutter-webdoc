null safety operator

1. null safety operator "?." -

void main() {
  String? x;   //Here x has null value.
  print(x.toUpperCase());  // ❌ Error
}


o/p
====
Error because here x is null. and toUpperCase() method can not be called on a null value.
To fix the issue we need to use "?.". -using this we can call toUpperCase() method on a null value. And the result will be null.

"If the value before ?. is not null, then do the operation.
But if it is null, don’t do anything — just return null safely."


void main() {
  String? x;  //Here x has null value.
  print(x?.toUpperCase());
}

o/p
====
The result is null .
