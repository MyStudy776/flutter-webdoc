Constructor

1. constructor Definition-

- Constructor always having same name as class Name.
- Whenever a class is called , bydefault constructor will be called.
- By default constructor is present inside the class.
- A constructor does not return anything.

2. Type of constructor-

- 1. Default constructor
- 2. Parameterised constructor
- 3. copy constructor

3. Create a constructor using class-

class myClass {

  //constructor
  myClass(){
    print("myClass Object created");
  }

  //A function inside the class
  int Add(int n1, int n2) {

    int sum = n1+n2;
    return sum;
  }
}

void main () {

  var myC = myClass(); //automaticall call the constructor
  print(myC.Add(5,6)); //calling the function
}

4. Another Example of constructor-

class Addition{
  
  void fun1(){
    print("I am bad");
  }
  
  void fun2(){
    print("I am not ok");
  }
  
  Addition(){
    int a = 3;
    int b = 7;
    print("The sum is ${a+b}");
  }
}


void main(){
  
  Addition obj1 = Addition(); //Automatically constructor called, when object created/defined
  
  obj1.fun1();
  obj1.fun2();
  
}

5. named parameter constructor - using required keyword 

class Addition{
  
  void fun1(){
    print("I am bad");
  }
  
  void fun2(){
    print("I am not ok");

7. Without constructor, what is the problem?

class Vehicle {
  int wheel; //❌ Error, Non nullable instance field 'wheel' must be initialized.
  }

8. With constructor, no error

  class Vehicle {
  int wheel;
  Vehicle(this.wheel){} //constructor, need to  pass argument using this keyword
  }
  
Note:
------
- we must initialize a variable , if we do not use constructor.
- But if we use constructor, we can declare variable, without initializing.

12. Abstract class with constructor

abstract class Vehicle {
  int wheel;
  Vehicle(this.wheel){} //constructor  of parent class
  void wheelnum(
  
  ); //abstract class method without body
  }

class Car extends Vehicle{
  Car(super.wheel); //constructor of child class
  void cartype(){
    print('I am great');
  }
  
  //The below method must use, because, it is present in abstract parent class
  @override
  void wheelnum(){
    print('The value of wheel is $wheel');
  }
  
}
  


void main(){
  
  var  car = Car(30);//must pass an argument
  car.cartype();
  car.wheelnum();

}

======
I am great
The value of wheel is 30

13. Using of this keyword

class Addition{
  
  int a = 100;
  int b = 200;
  
  void fun1(int a, int b){
    print("I am using local value");
    print("x = $a, Y= $b");
  }
  
 void fun2(int a, int b){
    print("I am using global value");
    print("x = ${this.a}, Y= ${this.b}");
  }
 
}


void main(){
  
  Addition obj1 = Addition();
  
  obj1.fun1(30,40);
  obj1.fun2(30,40);
  
}


output
=======
I am using local value
x = 30, Y= 40
I am using global value
x = 100, Y= 200
