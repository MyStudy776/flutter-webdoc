5. ?? operator -

- In Dart, the ?? operator is known as the null-aware assignment operator. 
- It is used to assign a value to a variable only if that variable is currently null.

void main()
{
    int a = 10;
    int b = 20;      
    var d = 20;
    var h;
    d ??= a + b; // d is not null, so it will not assign a new value.
    h ??= a + b; // h is null, so it will assign a new value.
    print(d);
    print(h);

}

o/p
=====
20
30
