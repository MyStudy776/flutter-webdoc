8.Function - named parameter and positional parameter -

Positional parameter
=============
void main() {
  describe('Raju', 8);
}

void describe(String name, int age) {
  print('My name is $name and I am $age years old.');
}


named parameter
================
void main() {
  introduce(name: 'Rani', age: 7);
}

void introduce({required String name, required int age}) {
  print('Hello! My name is $name and I am $age years old.');
}
 
required means you must give that value.

16. Multiple returns using records -

void main() {
  var (sum, product) = calculate(4, 5);
  print('Sum: $sum, Product: $product');
}

(int, int) calculate(int a, int b) {
  return (a + b, a * b);
}
 
o/p
====
Sum: 9, Product: 20
