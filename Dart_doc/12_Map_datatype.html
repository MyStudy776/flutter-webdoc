Map datatype

1. Map -


- Maps are dictionary type data type.
- It exists in key- value form. Lock -key concept.
- There is no restriction on the type of data that goes in Map data type. Any kind of data(like string, list, bool, int etc) can be stored inside Map.
- It does not have any order.
- Key should be unique.

2. Map. -

- Key pair value

void main() {
  Map x = {};
  x["a1"] = 'aa';
  x["b1"] = 12;
  x["c1"] = true;
  print(x);
}

o/p
===
{a1: aa, b1: 12, c1: true}

The error message you are encountering is due to null-safety rules in Dart.
Starting from Dart 2.12, Dart introduced null safety, which means that variables can't hold null values unless explicitly specified. In your case, the error is due to the possibility that the key 'k2' might not exist in the map or that the value associated with 'k2' might be null.
