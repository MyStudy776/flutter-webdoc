String datatype

1. Sets-

- It is a special case in List.
- It does not contain duplicate value.
- It is unordered array.

void main()
{
 var x = {'Rama',  "Asha"};
 print("Output is: $x");

 Set y = {'gamo','gigi','gigi'};
 print("Output is: $y");

}

o/p
===
Output is: {Rama, Asha}
Output is: {gamo, gigi}

2. Set commands-

void main()
{
 var x = <String>{'Rama',  "Asha"}; // Declaring set in First Way
 print("Output is: $x");

 Set<String> y = {'gamo','gigi','gigi'};// Declaring set in Second Way
 print("Output is: $y");

 print(y.length);
 print(y.elementAt(1));
 print(y.contains('gamo'));
 print(y.contains('pupa'));

 y.remove('gamo');
 print(y.length);

}


o/p
===
Output is: {Rama, Asha}
Output is: {gamo, gigi}
2
gigi
true
false
1


1.	variable_name.elementAt(index);	It returns the element at the corresponding index. The type of output depends on the type of set defined.
2.	variable_name.length;	It returns the length of the set. The output is of integer type.
3.	variable_name.contains(element_name);	It returns boolean value true if the element_name is present in the set else return false.
4.	variable_name.remove(element_name);	It deletes the element whose name is present inside it.
5.	variable_name.forEach(…);	It runs the command defined inside forEach() function for all the elements inside the set.
6.	variable_name.clear();	It deletes all the element inside the set.

4. addAll in sets -

void main()
{
 var x = <String>{'Rama',  "Asha"};
 var y = <String>{'aa',  "bb"};
 print("Output is: $x");
 print("Output is: $y");
 y.addAll(x);
 print("Output is: $y");
}

o/p
===
Output is: {Rama, Asha}
Output is: {aa, bb}
Output is: {aa, bb, Rama, Asha}
